# Bibliothèque de prompts

Copie, colle dans Claude, remplace ce qui est entre [crochets].
Quand une formulation marche bien pour toi, ajoute-la en bas, dans « Mes prompts ».

---

## 1. Premier montage

```
Monte [nom du fichier] en Reel : coupe les silences, et quand je répète une phrase, garde la dernière prise.
```

```
Nouveau Reel : j'ai mis ma nouvelle vidéo dans rushes. Crée un nouveau projet et fais le premier montage avec ma charte.
```

## 2. Corriger une coupe

```
À [0:12], la coupe est trop sèche, laisse respirer 0,2 seconde.
```

```
Enlève le passage où je dis « [phrase à supprimer] ».
```

## 3. Sous-titres

```
Mets les sous-titres plus haut pour ne pas cacher mon visage, trois mots maximum à la fois, en majuscules.
```

```
Relis les sous-titres et liste-moi les mots qui ont l'air mal transcrits.
```

```
Remplace [Clod] par [Claude] partout.
```

## 4. Effets

```
Ajoute un titre d'accroche « [ton titre] » au début, un zoom quand je dis [mot], et surligne le mot [mot].
```

```
Ajoute une transition entre mes deux idées principales. Propose-m'en trois dans la bibliothèque.
```

```
Quand je cite mes trois offres, fais-les tourner en orbite autour de moi (carousel-orbit), à mes couleurs.
```

```
Montre-moi 3 effets de la bibliothèque qui iraient bien avec cette vidéo, et explique-moi ce que chacun apporte.
```

```
Il y a trop d'effets : garde seulement les trois plus importants.
```

## 5. Musique

```
J'ai mis musique.mp3 dans rushes : mets-la à 10 % du volume sous ma voix, et fais-la monter à la fin.
```

```
Enlève la musique, je l'ajouterai dans Instagram.
```

## 6. Export et couverture

```
Exporte le Reel en MP4.
```

```
Crée une image de couverture avec le titre d'accroche, à partir de l'image où je souris le plus au début.
```

## 7. Quand ça plante

```

```

```
Ma vidéo iPhone ne s'affiche pas dans l'aperçu, convertis-la.
```

## 8. Idées et accroches

```
Voici des questions qu'on m'a posées en DM : [colle-les]. Propose-moi 5 idées de Reels avec une accroche de moins de 8 mots pour chacune.
```
