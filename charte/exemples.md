# Trois chartes d'exemple

Pour voir à quel point le même kit peut changer de style. Demande à Claude : « Montre-moi ma dernière vidéo avec la charte douceur. »

## Énergie
- Couleurs : texte `#FFFFFF`, accent `#E0283F`, texte sur l'accent `#FFFFFF`, sombre `#1C1315`
- Polices : titres **Anton**, sous-titres **Anton**
- Sous-titres : grands (taille 84), mot actif sur fond d'accent
- Rythme : dynamique, coins peu arrondis

## Douceur
- Couleurs : texte `#FFFDF8`, accent `#B9C8B0`, texte sur l'accent `#2F3A2F`, sombre `#2F3A2F`
- Polices : titres **Instrument Serif**, sous-titres **DM Sans** (500)
- Sous-titres : moyens (taille 64), mot actif en couleur
- Rythme : doux, coins très arrondis

## Expertise
- Couleurs : texte `#FFFFFF`, accent `#F2C14E`, texte sur l'accent `#1F2A44`, sombre `#1F2A44`
- Polices : titres **Hanken Grotesk** (800), sous-titres **Hanken Grotesk** (700)
- Sous-titres : moyens (taille 68), mot actif sur fond d'accent
- Rythme : doux, coins légèrement arrondis
